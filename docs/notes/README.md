# Decision notes

One short note per starred algorithm from `../05-patterns-and-algorithms.md`.

Each note answers four questions and nothing else:

1. What problem was I solving?
2. What did my own implementation do, and what did it measure?
3. Did I keep it or swap in a library — and why?
4. What surprised me?

Keep them to a paragraph or two. By week 8 this folder shows judgement rather
than output, which is the harder thing to demonstrate.
